Privacy Policy

DevUtil is a Chrome extension that provides formatting, conversion, encoding, time, and generation tools for developers. This policy explains how DevUtil handles data.

Effective August 14, 2026 · Applies to version 0.1.0

Summary

DevUtil processes data locally in your browser. It has no backend, does not transmit your tool content to the developer or third parties, and does not use analytics, advertising, telemetry, or tracking.

Data DevUtil processes

DevUtil processes text and files only when you use a related formatting, conversion, encoding, decoding, hashing, comparison, time, or generation feature. Processing is performed locally within the extension.

DevUtil does not upload this content or send it to an external service. Uploaded files are read locally and are not transferred to the developer or third parties.

Local storage

DevUtil uses browser-local extension storage to restore non-sensitive preferences and workspace state between popup sessions. This may include:

  • Theme and navigation preferences.
  • Favorite and recently used utilities.
  • Non-sensitive input, output, and selected tool options.

JWT values, generated passwords and random strings, and bcrypt plain text or hashes are not persisted. If an uploaded JSON file populates an input field, that populated text may be retained locally as part of the tool's workspace state.

You can remove locally stored data by clearing the extension's data, uninstalling the extension, or resetting the relevant browser profile.

Chrome permissions

DevUtil requests only the storage permission. It is used to retain the preferences and non-sensitive state described above. DevUtil does not request access to browsing history, visited websites, tabs, or page content.

Data sharing and sale

DevUtil does not sell, rent, share, or transfer user data to third parties. Data is not used for advertising, profiling, credit decisions, lending, or purposes unrelated to DevUtil's developer utility features.

Analytics, tracking, and remote code

DevUtil does not use analytics, advertising, telemetry, tracking technologies, or remote executable code. Runtime code and processing libraries are included in the extension package.

Limited Use

DevUtil's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide or improve DevUtil's single-purpose collection of local developer utilities and is not transferred except where required by law or necessary for security.

Changes to this policy

This policy may be updated when DevUtil's functionality or legal obligations change. The revised policy will be published on this page with a new effective date and the applicable extension version.

Contact

For privacy questions, support, or deletion requests, open an issue in the public support tracker.
